# separatix documentation

`separatix` is a transparent pretraining diagnostic for supervised feature
spaces. It compares simple probe families, measures geometry and neighborhood
structure, and reports confidence-aware guidance about how much model
complexity the observed data appear to justify.

It is a diagnostic and auditing tool, not an automatic model selector. Start
with the [quickstart](quickstart.md), then read the
[decision pipeline](decision_pipeline.md) when you need to audit why a
recommendation was made.
